# Calculator Vault — آلة حاسبة + خزنة سرية

تطبيق Android Studio (Kotlin) يعرض نفسه كآلة حاسبة طبيعية 100%، وعند كتابة الرمز **1234** ثم الضغط على **=** يفتح لك الخزنة المخفية.

## المزايا

- آلة حاسبة حقيقية (جمع/طرح/ضرب/قسمة/نسب/أقواس + معاينة نتيجة لحظية) من خلال مكتبة `exp4j`.
- الخزنة تحتوي على:
  - **إخفاء الملفات (صور/فيديو/PDF/…)** بتشفير AES-CBC داخل مجلد خاص بالتطبيق.
  - **إخفاء التطبيقات**: تشغيل مخفي + قائمة التطبيقات المقنّعة داخل التطبيق.
  - **الإعدادات**: تغيير الرمز السري.
- لا يظهر أي شيء يدل على وجود خزنة في الواجهة الرئيسية.

## الرمز الافتراضي

`1234` ↩ ثم اضغط `=`

يَلْتقط التطبيق أيضًا لو كتب المستخدم `12+34` أو `1*2*3*4` فيتم فتح الخزنة بعد أن يَستخرج الأرقام ويُطابقها على `1234`.

## كيفية البناء (Build)

1. افتح **Android Studio Hedgehog (2023.1.1 أو أحدث)**.
2. اختر `File > Open` وحدد مجلد `CalculatorVault/`.
3. سيقوم Gradle بتنزيل نفسه تلقائيًا؛ إن لم يحدث، من داخل المشروع نفّذ في الترمنال:
   ```bash
   ./gradlew assembleDebug
   ```
   (على Windows: `gradlew.bat assembleDebug`).
4. بعد البناء، ستجد ملف `app/build/outputs/apk/debug/app-debug.apk` جاهز للتثبيت.

## التثبيت على الجهاز

- وصّل جهازك أو افتح محاكيًا.
- اضغط **Run ▶** في Android Studio.
- أو ارفع ملف الـ APK مباشرة على الجهاز وثبّته (قد تحتاج تفعيل “تثبيت من مصادر غير معروفة”).

## ملاحظات أخلاقية وقانونية

- هذا المشروع **تعليميّ** فقط.
- إخفاء ملفات الآخرين دون إذن يُعدّ انتهاكًا للخصوصية، يُرجى الاستخدام ضمن الإطار القانوني.
- نظام Android لا يسمح لتطبيق مستخدم بإخفاء أيقونة تطبيق آخر في المشغّل، فميزة «إخفاء التطبيقات» هنا تعني تشغيل التطبيق المختار من داخل هذه الخزنة بدلًا من سطح المكتب، مع حفظ قائمتك المفضّلة المموّهة.
